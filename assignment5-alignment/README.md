## TL;DR: 1.5B 参数下的“R1”推理能力演进

本项目在单卡 4090 (48G) 资源约束下，复现了类 DeepSeek-R1 的推理能力演进逻辑。通过对 **Dr.GRPO 算法的无偏适配** 与 **“白金级”数据治理**，成功验证了小参数模型在复杂逻辑任务上的涌现潜力与泛化边界。

#### 1. 核心实战战绩 (Verified Metrics)

- **MATH-500 潜力兑现**：Pass@1 从 Baseline 的 **14.4%** 提升至 **60.6%** (RL w/o std 变体)；其知识上限 **Pass@64 达到 93.6%**，几乎完全追平官方 Instruct 模型的 93.8%。

- **竞赛级逻辑跨越**：在 AIME 2024 中实现 **40.0%** 的 Pass@64 解决率；在 AIME 2025 压力测试下维持 **36.7%** 的 Pass@64 性能。

- **全梯度难度对齐**：基础任务 GSM8K Pass@1 达到 **80.6%**；中程推理任务 AMC12 Pass@1 从 2.4% 跃升至 **36.1%**。

  

#### 2. 核心技术 Insight

- **Dr.GRPO 无偏适配**：针对单卡小 Batch 场景，通过**移除标准差归一化 (std-norm)** 解决了奖励信号震荡问题。实验显示，该改进在高难度 AIME 任务中使采样上限性能显著提升 (40.0% vs. 标准 GRPO 30.0%) 。

- **数据极简主义**：摒弃万级噪声数据，仅通过 **3,000 条逻辑蒸馏的“白金样本”** 完成 SFT 冷启动。通过调整 Loss Mask 策略诱导模型**自主触发 `<think>` 标签**，实现了从行为模仿到逻辑内化的突变。

- **推理“内化压缩”规律**：量化观测到思维链长度呈 **“倒 U 型”演变** (~1102 → ~817 tokens) 。RL 作为逻辑剪枝器，在不损知识上限的前提下将推理成本降低约 **25%**。

  

#### 3. 科学发现与病理诊断

- **推理留存率 ($\Delta R$) 框架**：提出以 AIME 24 vs. 25 作为“自然实验”场，定义“留存率”指标评估模型逻辑纯度。

- 数据泄露诊断：观察到AIME24和25测试中baseline模型的反常表现，用推理留存率衡量Qwen模型在AIME24和25的表现差异，并通过一个具体的求解案例与两个测试集上正确样本的分布差异确认了数据泄露的大概率存在。

- **归纳摩擦 (Inductive Friction) 假说**：推导并验证了算法无偏性在不同分布下的代价——Dr.GRPO 虽然在稀疏奖励区（难题）表现优异，但在密集奖励区（易题）因探索方差较大导致 Pass@1 略有回撤。

## Chapter 1 摘要
<a id="section-1"></a>

### 1.1 **项目概述**

<a id="section-1-1"></a>

本项目在单卡4090 (48GB VRAM) 上成功复现了 类 DeepSeek-R1 的推理能力演进流程 。我们以 **Qwen-2.5-Math-1.5B** 为基座模型，通过利用`HuggingFaceH4/Bespoke-Stratos-17k`**构建“白金数据”监督微调 (SFT)** 与 **GRPO 强化学习算法**，有效引导出了1.5B 参数规模模型的数学推理能力。

实验证明，通过极简的高质量 SFT 冷启动与针对性的 RL 算法改进，小参数模型不仅能习得严谨的 XML 格式规范，更能在逻辑链条上实现从“机械模仿”到“内化压缩”的质变。



### 1.2 **核心战绩**

<a id="section-1-2"></a>

**性能突破**：MATH-500 从 14.4% 提升至 60.6%，Pass@64追平官方模型(93.6% vs 93.8%),  在AIME25上实现36.67%的Pass@64, 并在k <= 16内表现持平甚至超越官方模型。

**数据效率**：通过数据蒸馏，以 **3,000 条样本** 胜过万级噪声数据，实现 88% 的训练减量与 2.4 倍的精度增益。

**采样阶跃**：RL 后的 $k=1$ 表现追平 SFT 的 $k=4$。



### 1.3  **技术策略与算法适配**

<a id="section-1-3"></a>

- **Dr.GRPO 算法的工程实践**：
  
  - **适配逻辑**：针对单卡小 Batch 场景，复现了 Dr.GRPO 中去除标准差归一化与动态长度归一化的策略，以尝试解决标准 GRPO 在极端资源受限下的训练波动问题 。
  - **实证发现**：实验显示，在 AIME 2024 等高难度任务中，Dr.GRPO 变体对比标准 GRPO 表现出了更高的峰值准确率（AIME24 40.0% vs 30.0%）与更稳健的收敛趋势。
  
- **单卡训练优化**：
  
  - **权重进程内同步**：针对 **On-policy 强化学习**频繁采样的特性，通过**内存级权重同步机制** 替代了传统的磁盘 IO 中转，确保了模型在单卡 4090 环境下的高效迭代。
  - **分批概率计算 (batched LogProbs)**：将引用模型的生成概率计算微批次化，显著缓解4096序列长度训练下采样旧策略时的瞬时显存峰值。
  
- **推理演化行为洞察**：
  
  - **思维链“倒 U 型”演化**：量化观察到了 CoT 长度从“直觉”到“模仿”再到“内化压缩”的动态演变（~1102 $\rightarrow$ ~817 tokens），揭示了 RL 带来的逻辑密度提升。
  
    

### 1.4  奖励机制与评估标准

<a id="section-1-4"></a>

项目中的评分框架基于 **CS336 Assignment 5** 的官方框架构建，通过集成成熟的数学校验逻辑，重点探究 1.5B 模型在强化学习中的行为演化。

#### **A. 核心评分框架**

模型必须在满足硬性格式约束的前提下，才有机会获得正确性奖励 ：

- **格式对齐 (Format Reward):** 响应必须遵循标准的 XML 标签闭合协议 。
- **结果校验 (Answer Reward):** 采用“全有或全无”的硬约束评分。仅当模型在规定格式内输出正确答案时，方可获得奖励分值。



#### **B. 评估引擎说明**

**[注] 以下模块集成自 CS336 官方基架代码，确保了与业界主流推理模型评测标准的一致性**

- **数学校验引擎:** 结合了 `MathD` 规范化与 `SymPy` 符号代数检查，通过 `sympy.simplify` 识别数学上等价但表达形式不同的解。

- **LaTeX 鲁棒处理:** 采用 `math_verify` 和 `latex2sympy` 自动剥离单位（如 `degree`, `cm`, `mile`）及处理混合分数（如 `7 3/4` 转为 `7+3/4`），确保模型不会因微小的格式扰动而丢失奖励。

- **重复性检测 (`repeatness`):** 内置基于 **后缀数组 (Suffix Array)** 与 **LCP (最长公共前缀)** 的字符串自相关算法。当逻辑循环率超过 0.2 时触发惩罚

  

#### **C. 行为干预机制**

针对观测到的 "Length Hacking" 现象，我们在 RL 阶段引入了干预 ：

- **非线性长度惩罚 (`length_penalty`):** 针对超过 3,072 Tokens 的冗长响应实施非线性惩罚（每 100 Tokens 扣除 0.02 奖励分），实现了约 25% 的推理密度提升 。

  

#### **D. 格式容错预处理**

为了缓解 1.5B 模型在训练初期对 XML 标签边界控制不精确导致的奖励丢失，本项目在调用官方评测逻辑前引入了自定义的鲁棒化处理层：

- **空格/换行对齐：** 自动识别并修复模型输出中常见的格式微瑕，如 `</think><answer>`（缺失空格）或 `</think>\n<answer>`（多余换行）。

- **设计动机：**在 GRPO 采样过程中，这些微小的 Token 差异不应影响对核心逻辑能力的评估。通过预处理，我们将 **“格式对齐”** 的学习门槛从“字符级匹配”放宽到了“语义标签匹配”，有效提升了训练初期的有效信号捕捉率，避免了模型因琐碎的格式错误而陷入无法收敛的困境 。



### 1.5 评测协议与口径统一性

<a id="section-1-5"></a>

为了确保 Baseline、SFT、RL 模型与官方 Instruct 模型之间的公平对比，本项目构建了两套对齐的评测流水线，核心逻辑如下：

#### **A. 统一的 Pass@K 评估逻辑 (`evaluate_passk.py`)**

- **带早停的迭代采样 (Early Stopping):** 考虑到资源因素，脚本实现了高效的 早停Pass@K 逻辑。对于每一道题目，若在第 $i$ 次尝试中获得正确解（Reward=1.0），则立即停止后续采样。

- **计算效率:** 统计 Pass@1 到 Pass@K 的解决率变化趋势，能够清晰观测模型从“博学但犹豫”到“自信且精准”的分布锐化过程。

  

#### **B. 适配模型特征的 Prompt 策略**

针对不同来源的模型，我们严格遵循其训练时的分布协议：

- {官方Baseline预训练基座模型}: 作为对比，使用自定义XML模板，以测试zero shot下预训练模型的指令遵循能力。

- **自研模型 (SFT/RL):** 使用自定义 XML 模板（`r1_zero.prompt`），并配合 `robust_reward_fn` 进行容错解析。

- **官方 Instruct 模型:** 动态加载对应模型的 `tokenizer.apply_chat_template`，确保对比基准处于其官方推荐的最佳性能状态。

  

#### **C. 核心判定逻辑的对齐**

尽管输出格式各异，但所有模型共用一套**数学判定引擎 (`grade()`)**：

- **对 RL 模型:** 采用 `r1_zero_reward_fn`，强制检查 `<think>` 和 `<answer>` 标签的完整性。

- **对官方 Instruct 模型:** 采用 `qwen_instruct_reward_fn`。该函数不强制要求 XML 标签，而是直接提取 `\boxed{}` 内容进行数学一致性校验，确保不因格式差异惩罚官方模型的数学能力。

  

#### **D. 推理参数配置**

所有评测均在 **vLLM** 引擎上完成，以保证推理效率与显存占用的最优平衡：

- **采样常规设置:** Temperature=0.7, Top-p=0.95, Max_tokens=4096。

- **停止符设置:** RL 模型使用 `</answer>`或`<|endoftext|>` 停止，Instruct 模型适配 `<|im_end|>` 与 `\n\n\n` 等官方推荐标识符。

## Chapter 2 训练流水线设计：从行为模仿到逻辑内化

<a id="section-2"></a>

本项目采用两阶段演进策略，旨在平衡 1.5B 小参数模型的“格式对齐”与“推理潜力激发”。

### 2.0 Prompt设计

<a id="section-2-0"></a>

![prompt](asset/rendered_prompt.png)
<p align="center">图1 为复现R1-zero构建的System Prompt</p>



Prompt 的设计在本复现中并非简单的文本提示，而是**RL训练的“契约”**。我们构建了一个**强结构化（Structurally Enforced）**的 System Prompt，其核心包含两个维度的约束:

1. **拓扑约束 (Topological Constraint)**：强制模型输出 <think> 和 <answer> 标签对。这不仅是为了格式整洁，更重要的是为后续的 **Format Reward** 提供了可计算的**锚点（Anchor）**，使奖励模型能精确区分‘推理流（CoT）’和‘最终结论’
2. **思维触发 (Reasoning Trigger)**：通过指令显式要求 *'think about the solution process'*，在 SFT 阶段诱导模型生成长思维链，从而为 RL 阶段的**GRPO**提供了可被优化的**搜索空间（Search Space）**。



这种‘硬约束’Prompt 是 R1 能够在不依赖**大量**符合think tag xml标签的结构化数据进行微调的情况下，涌现出自我反思能力的第一推动力。



### 2.1 **阶段一：格式对齐与冷启动**

<a id="section-2-1"></a>

SFT 阶段并非旨在向模型注入新知识，而是通过**行为克隆**为后续的强化学习提供高质量的“逻辑种子”与“风格基底”。

- **核心目标**：使基座模型学会 `User/Assistant` 对话模板，并熟练掌握 `<think>...</think>` 与 `<answer>...</answer>` 的 XML 标签规范

- **数据驱动的消融策略**：
  - 通过对 1.7 万条原始数据进行“去毒”处理，剔除了导致模型习得“啰嗦”和“死循环”的长上下文样本。
  - 最终采用 **SFT v6（3,000 条白金样本）**，通过格式清洗和逻辑蒸馏（强制答案极简），实现了 **44.10%** 的准确率，为 RL 阶段提供了最“诚实”的起点。
  
- **工程配置**：采用 Full Finetuning 模式，设置最大序列长度为 4096，确保逻辑链条的完整性。

- **协议自触发机制**：通过调整 SFT 阶段的 Loss Masking 策略，将 `<think>` 引导符从“Prompt 引导区”移入“Loss 计算区”。这一改进强制模型在没有任何格式暗示的情况下，从零开始自主预测思考链的起始标识，实现了从“被动接收指令”向“主动触发逻辑协议”的质变，旨在验证标签预测的契约深度对复杂推理潜力的启发作用。

  

### 2.2  **阶段二：逻辑强化与演进**

<a id="section-2-2"></a>

强化学习阶段旨在通过**组内相对优势 (Group Relative Advantage)** 激发模型的自我修正能力，使其从“机械模仿”进化为“深度推理”。

- **算法选择与适配**：

  - **复现 Dr.GRPO**：针对单卡（RTX 4090 48GB）小 Batch 训练不稳定的痛点，我们参考 Sea AI Lab 的研究，移除了 Advantage 计算中的**标准差归一化**与**动态长度归一化**。

  - **优势**：相比于标准 GRPO，Dr.GRPO 在高难度任务（如 AIME）中表现出更强的鲁棒性，有效避免了小规模采样下的梯度方向偏移。

    

- **多维度奖励函数设计 (Reward Designing)**：
  - **严格 XML 耦合奖励 (Coupled Reward Logic)**：
  
    - **逻辑**：奖励计算完全依赖于 XML 解析器。若 `<think>` 或 `<answer>` 标签格式不规范，系统将直接判定为“无法提取答案”并给予 **0 分** 的 Answer Reward 。
    - **意义**：这建立了一个“全有或全无”的硬约束环境。模型必须首先内化格式规范，才有机会通过正确逻辑获取更高的奖励分值，从而实现了格式规范与逻辑推理的协同阶跃式进化。
  
  - **长度敏感型惩罚 (Length-Aware Penalty)**：
  
    - **策略**：为超过 **3,072 Tokens** 的响应引入与长度呈正相关的非线性负奖励。
    
    - **设计初衷与逻辑优化**：
      - **现象观测**：实验数据表明发现，格式错误样本的 Token 长度普遍逼近 4,096 的物理上限（均值 > 3,500）。
      
      - **算法偏见**：这种“长而错”的现象揭示了标准 GRPO 在处理负样本时存在的**长度偏差 (Length Bias)** 风险。当模型因逻辑死循环而无法输出 EOS 终止符时，极长的无效生成不仅耗尽了计算资源导致物理截断 ，还可能在组内优势计算中因长度与奖励的非良性耦合而产生误导信号 。
      
      - **干预效果**：通过引入 **3,072 Token 惩罚项**，我们对超长响应施加了显著的负向激励 。这一举措有效遏制了模型通过无限逻辑循环来逃避得出结论的 **Length Hacking** 行为 ，迫使模型在安全长度区间内进行“内化压缩”，从而实现了更高的逻辑密度与更稳健的推理行为 。
      
        
  
- **稳定性机制**：引入 PPO 风格的 **Trust Region Clipping**，在单卡环境下无需持续运行昂贵的reference模型即可维持训练稳定。

  

### 2.3 **行为演化观测**

<a id="section-2-3"></a>

通过这一流水线，我们观察到了模型推理行为的质变：

- **“去肥增肌”演化**：RL 阶段充当了逻辑剪枝器，剔除了 SFT 阶段因模仿而引入的冗余复读，将平均思维链长度从 ~1,102 优化至更具逻辑密度的 ~817 Tokens 

- **效率与精度同步提升**：GRPO 不仅将 Pass@1 准确率推至 **83.4%**，更在保持高精度的同时使推理成本降低了约 25% 。

## Chapter 3 SFT 数据治理

<a id="section-3"></a>

**基于数据的核心发现：**

**训练效率阶跃**：SFT v4 (Platinum) 仅需 3,000 步即可在 MATH 上取得 44.1% 的准确率 ，相比 v1 版本，在减少 88% 训练量的同时，准确率提升了约 2.4 倍 。

**Epoch 的负面效应**：对比 SFT v3 的演化（Epoch 1 -> 2），虽然准确率提升了 9%，但正确样本的中位数长度从 1374 膨胀至 1520 。这表明持续训练会导致模型习得“冗长 = 正确”的偏见，而非真正的逻辑进步。

**格式错误与物理截断的强相关**：数据记录显示，格式错误样本的长度中位数（3931）极度接近 4096 的上限 。这为我们后续在 RL 阶段引入 **3072 Token 长度惩罚** 以遏制 Length Hacking 提供了量化支持。



实验通过对1.5B小参数模型的系统性消融研究，证实了核心论点：**数据的纯度（正确性与格式规范）远比数量重要。** 以下是SFT数据策略从“粗放”到“精细”的完整演变路径：

##### 1. 早期探索：噪声干扰与长程迷失 (v1 - v2)

- **初始状态 (v1)：** 采用随机抽取的5k数据（含噪）。模型不仅学习了推理，也由噪声数据学会了冗余废话，导致输出过长而被物理截断，准确率仅18.00%，且格式错误率极高。

- **长度过滤尝试 (v2)：** 为解决截断问题，简单过滤掉长度大于4k的样本。结果引发了**“死循环现象”**（如反复输出"Wait..."），准确率跌至15.64%。这表明单纯截断长样本会导致模型在长程推理中迷失方向。虽然通过引入1.05的重复惩罚强行提升了准确率（至45.54%），但这掩盖了模型本身未能学会“何时停止”的缺陷。

  

##### 2. 格式规范化：截断与过拟合的博弈 (v3)

- **格式清洗 (v3 E1)：** 引入reward_fn评分，仅保留格式干净（Tag完整）的样本。模型具备了解题能力（准确率回升至40.02%），但缺乏停止机制。数据显示，格式错误样本的中位长度逼近4096上限，说明大多数错误是因未预测到EOS导致的**物理截断**。

- **增加训练 (v3 E2)：** 试图通过增加Epoch提升效果，虽准确率提升至49.48%，但出现了**“风格过拟合”**。正确样本长度从1374膨胀至1520，模型习得了“冗长=正确”的错误偏见，变得更加啰嗦，且截断风险依然高企。

  

##### 3. 结构重塑与逻辑内化：质的飞跃 (v4)

- **结构化分离 (v4.1)：** 实施“思考清洗”与“答案蒸馏”。剔除思考过程中的答案泄露，并强制精简<answer>标签内容。这一强约束使模型学会了“思考”与“表达”的明确界限，生成的正样本极其干净。

- **指令自触发 (v4.2 - 最终选用版)：** 进一步调整Loss计算策略，将<think>起始标签纳入Loss计算。这一微小的改动将模型从“被动接受Prompt引导”转变为“主动预测思考标签”，极大地强化了思维逻辑的内化与自发触发能力。
  
  - **最终成效：** SFT v4.2仅需 **3,000步** 训练，便在MATH上取得了 **44.10%** 的准确率。相比v1版本，在 **减少88%训练量** 的同时，准确率提升了约 **2.4倍**，且平均长度大幅优化至2,158，实现了高效与精准的双重突破。
  
    

##### 4. 后续展望 (v5)

鉴于v4版本清洗过于极致，且SFT数据来源单一，导致清洗出的数据缺乏内容和形式上的多样性，模型泛化性不足（易产生模式崩塌）。

v5 计划重新引入精选的优质长推理数据，包括推理风格多样化和来源于难度多样化题目的规范化CoT，以提升泛化能力与多样性表现。

### 3.3 惯性与语义的冲突——Prompt修正实验

##### 结果解析：一场关于“顺应”与“对抗”的博弈

上述六组实验结果，实质上揭示了大模型在微调过程中，**预训练本能（Nature）** 与 **后天对齐（Nurture）** 之间的深层博弈。从基座模型的角度出发，可以看到其对Prompt中的\n和空格的区分极为敏感，当提示词中的</think>和<answer>之间被\n这个预训练中语境割裂意味极重的token割裂开来时，预训练的文本补全本能难以捕捉到两者间的关联，便难以建立起好的指令遵循能力。相比之下，空格作为一个软过渡的token就能让模型更好的捕捉到两个tag之间的衔接关系。

##### 1. 顺势而为：为什么“原版SFT”是版本答案？

**原版 SFT (Prompt空格 + Data换行)** 之所以能取得 **51.6%** 的最高分，是因为它巧妙地达成了一种“认知分工”：

- **输入端（Prompt）：** 保留空格。这顺应了 Base Model 对自然语言“流连贯性”的偏好。模型读到空格时，注意力机制能更顺畅地将 System Prompt 的语义传递给后续生成的 Token。
- **输出端（Data）：** 强制换行。这利用 SFT 的强监督信号，强行建立了结构化的输出规范。
- **结论：** 这是一种**“外圆内方”**的策略——对输入宽容（符合直觉），对输出严格（符合规范）。这种策略最小化了模型处理 Prompt 时的认知负担。

##### 2. 过犹不及：为什么“改版SFT”反而变弱了？

**改版 SFT (全链路换行)** 试图在逻辑上追求绝对的“训练-推理一致性”，结果却遭遇了滑铁卢（最高仅 46.2%）：

- **对抗归纳偏置：** 当我们把 Prompt 中的空格也改为换行，我们实际上是在强迫模型去**“遗忘”**它在预训练中学到的通用语言规律（即：空格是连接词，换行是断句）。
- **参数浪费：** 模型被迫分配宝贵的参数容量去适应这个两个逻辑相同的tag用换行隔开的“反直觉”的 Prompt 格式，而不是专注于数学推理本身。这就是所谓的**“归纳摩擦 (Inductive Friction)”**。

##### 3. 鲁棒性的悖论：噪声即抗体

对比 **原版SFT** 和 **改版SFT** 在面对“原版Prompt（空格）”时的表现（51.6% vs 20.0%），我们可以看到：

- **原版SFT** 因为训练时存在“Prompt空格 vs Data换行”的错位，这种错位充当了一种**天然的数据增强（Data Augmentation）**。它教会了模型：“无论 Prompt 怎么写，我都要按标准格式输出”。

- **改版SFT** 在温室中长大，从未见过这种不一致，因此极度脆弱，丧失了泛化能力。

  

##### 结论

在小参数模型的工程实践中，**最好的微调策略不是去“纠正”基座的直觉，而是去“利用”它。** 哪怕这在人类看来包含一点逻辑上的小瑕疵（如 Prompt 中的空格），只要它符合模型的概率分布本能，就是提升性能的关键支点。



### 3.4 SFT阶段结论：一场精密的“行为外科手术”

<a id="section-3-4"></a>

综合以上三个层面的系统性消融实验，我们可以得出结论：对于1.5B这样的小参数模型，监督微调（SFT）阶段的核心逻辑并非传统的**“知识注入”**，而是一场旨在**“激活潜力”**与**“塑造行为”**的精密外科手术。这一阶段的成功，为后续强化学习（RL）算法的高效探索和潜力兑现奠定了坚实的基础。其核心逻辑可被提炼为以下三点：

1. **数据的纯度重要性远超数量:** 我们的数据策略演变路径（v1至v4）明确证实，对于小参数模型，噪声数据不仅无益，甚至有害。通过将数据集从5k含噪样本极致蒸馏至3k“白金”逻辑样本，我们不仅将训练量减少了88%，更实现了**从18.0%到44.1%的准确率飞跃**。这揭示了SFT的核心作用是提供一个**清晰、无歧义的“行为范本”**，而非知识的堆砌。

2. **格式即协议，纪律是基石 :** SFT的核心任务是为模型建立一套**高度机械化、可预测的输出“肌肉记忆”**。如SFT前后格式对比所示，通过强制的格式清洗与答案蒸馏，模型将 </think>\n<answer>\boxed{...}</answer> 的结构内化为一种行为协议。这不仅是为了输出的整洁，更是为后续强化学习（RL）阶段提供了**稳定、可解析的奖励锚点**，从根本上解决了奖励信号的归因难题，是逻辑链条得以“内化压缩”的先决条件。

3. **顺应而非对抗，化“摩擦”为鲁棒 :** “Prompt空格 vs. Data换行”的实验揭示了深刻的“**归纳摩擦 ”现象**。最佳策略并非强迫模型在输入端（Prompt）违背其预训练本能（Nature），而是**顺应其“阅读偏好”，同时在输出端（Data）强力塑造其“行为规范”（Nurture）**。这种“外圆内方”的策略不仅最小化了模型的认知负担，其固有的“指令-数据”错位甚至充当了一种天然的数据增强，显著提升了模型对微小扰动的泛化能力和鲁棒性。

## Chapter 4 算法重构：基于 Dr. GRPO 的无偏估计适配与复现

<a id="section-4"></a>

### 4.1 引言：单卡训练的物理约束与理论偏差

<a id="section-4-1"></a>

SFT 阶段的成功为模型奠定了“行为规范”，但要激发其逻辑的自我修正能力，必须引入强化学习（RL）。然而，在单卡（RTX 4090）资源受限的物理环境下，标准的 RL 算法面临严峻挑战。

**1. 小 Batch 下的方差震荡：**
标准 GRPO 依赖于**组内标准差归一化（Group Std-Norm）**来计算 Advantage。在单卡环境下，受显存限制，Group Size 往往被压缩得很小。根据统计学原理，小样本的标准差估计极其不稳定，这会导致奖励信号充满噪声，使模型难以收敛。

**2. 算法本身的理论偏差：**
受 Sea AI Lab 研究 *'Understanding R1-Zero-Like Training'* (Liu et al., 2025) 的启发，我们意识到标准 GRPO 引入的归一化项并非总是良性的。研究表明，标准 GRPO 存在**“回复长度偏差”**和**“难度偏差”**，这可能导致模型倾向于生成冗长但无效的回复——这恰恰解释了我们在早期实验中观察到的“死循环”倾向。

为了解决上述“物理约束”与“理论偏差”的双重矛盾，本章提出了一套基于 Dr.GRPO 的适配方案，旨在为 1.5B 小参数模型构建一个无偏、稳定的训练环境。



### 4.2 算法变体选择：从标准到无偏的演进之路

<a id="section-4-2"></a>

为了验证不同优化策略对小模型逻辑演化的影响，我们设计了三组对比实验，涵盖了从“工业界基准”到“学术界前沿”的演进路径：

**1. Baseline: Standard GRPO (标准版)**

- **定义：** 严格遵循 DeepSeekMath 论文定义的原始 GRPO 算法。

- **特征：** 包含优势计算中的 Std-Norm（标准差归一化）和隐式的长度归一化。

- **预期风险：** 在单卡小 Batch 下可能导致训练震荡；且倾向于鼓励长回复，增加模式坍塌风险。

  

**2. Ablation: GRPO w/o Std-Norm (去标准差版)**

- **定义：** 仅移除优势计算分母上的标准差项，保留其余逻辑。

- **设计动机：** 试图通过最简单的“去噪”手段，解决小 Batch 下分母波动过大的问题，是迈向无偏估计的中间态。

  

**3. Proposed: Dr.GRPO + Length Penalty (完全体)**

- **定义：** 采用 *Liu et al.* 提出的 **Dr.GRPO (GRPO Done Right)** 策略，彻底移除优势计算中的标准差归一化与长度归一化项，还原真实的策略梯度。
- **工程增强：** 针对 SFT 阶段暴露出的“模式坍塌”病理（见 Chapter 7），我们在 Dr.GRPO 的基础上额外引入了非线性的 **Length Penalty**。
- **核心假设：** 我们预期这一组合能在保证梯度估计无偏性的同时，有效抑制小模型的逻辑死锁，是在有限算力下实现高性能推理的最佳解。



**4. Reference-Free Policy Optimization (无参考模型策略优化)**

针对单卡 4090 的显存瓶颈与推理任务的特殊性，我们在实现中做出了一个关键的工程决策：**移除显式的 KL 散度惩罚项，并卸载 Reference Model。**

- **理论依据：** 不同于 RLHF 需要防止模型欺骗（Reward Hacking）人类的主观偏好，数学推理任务使用的是基于规则的**硬验证器（Hard Verifier）**。正如 *Liu et al. (2025)* 指出的，在这种场景下，模型必须通过真正的逻辑推理才能获得奖励，分布偏移（Distributional Shift）的风险极低。因此，强行将模型约束在基座模型的分布附近反而可能限制其探索更优解题路径的能力。

- **稳定性机制：** 实验观测表明，即便去除了 KL Loss，GRPO 目标函数中的 **Trust Region Clipping**（截断机制，$ϵ=0.1∼0.2$）

   已足以维持训练的稳定性。我们的 Approx KL 监控曲线在整个训练过程中保持平稳，未出现策略崩塌。

- **效率收益：** 移除 Reference Model 释放了约3 GB的显存，使我们得以在单卡上支持更大的 Batch Size 和更长的 Context Window（4096），这对 GRPO 的组内优势估计至关重要。



### 4.3 评测体系设计：有限容量下的有偏训练与全面评测

<a id="section-4-3"></a>

为了严格评估 1.5B 小参数模型在经受`Bespoke-Stratos-17k`高强度专项训练后的泛化边界，我们设计了一套严密的实验方案。鉴于训练数据高度集中于高难度竞赛题，这种环境虽然能迫使模型进行高强度的“逻辑压缩”，但也极易在有限的参数容量下引发对训练分布的过拟合。因此，构建一个能够有效甄别“真实逻辑泛化”与“机械样本记忆”的全面评测体系显得尤为关键。

基于此，我们构建了如下的一个涵盖基础、进阶与极限挑战的**三梯度评测矩阵**，以全面扫描模型的能力边界。

首先，以 **GSM8K 作为基础能力层**，旨在考察模型在习得奥数级解题技巧后，是否还能保持对简单应用题的“向下兼容性”与基础稳定性，以此检验是否存在灾难性遗忘。其次，将 **MATH 与 AMC12 划定为核心能力层**，作为观测泛化效应的主阵地；尽管受限于 1.5B 的物理容量，其绝对性能难以企及 70B+ 模型，但我们预期 RL 将在此区间带来显著的逻辑收益。最后，以 **AIME 设定为知识上限层**，这不仅是探测模型在“舒适区”内能力天花板的标尺，更是**检验 Dr.GRPO 算法鲁棒性的决胜战场**——在极限推理压力下，不同算法间的稳定性差异将被最大程度地放大。

在评估指标上，我们采用 **Pass@k** 体系来精细刻画模型的学习状态：通过 **Pass@1** 衡量模型的收敛能力与策略确定性，即“能否稳定输出首选正确解”。同时利用 **Pass@k 曲线** 描绘模型的潜力边界与搜索广度，探究在有限的参数空间内究竟“蕴藏”了多少潜在的正确解题路径。

- **搜索空间的深度挖掘**：这种增长意味着在面对复杂长链推理时，RL 能通过大规模采样和奖励机制引导模型找到那些 SFT 难以通过模仿触达的正确路径。

  

#### 3. 指标错位思辨：知识覆盖与输出稳定性

通过对比模型与 **Instruct（官方充分后训练模型）** 的 Gap，可以揭示当前训练状态的深层本质。

- **知识覆盖已近上限（Pass@64 Gap 极小）**：在 MATH-500 上，RL 模型的 Pass@64 为 **93.6%**，与官方模型的差距仅为 **-0.2%**。在 AIME 2025 上差距也缩小到了 **-3.3%**。这证明模型内部的“知识储备”和“解题潜力”已经非常接近顶尖水平。
- **确定性转化不足（Pass@1 Gap 较大）**：尽管潜力接近，但在“一次性做对”的能力上仍有明显短板。MATH-500 的 Pass@1 差距高达 **-14.0%**。这说明模型虽然“能做对”，但在推理路径的收敛性和确定性上仍显稚嫩，并未能稳定地将搜索到的潜力转化为首选输出。

- **质变结论：** 模型从 SFT 阶段的“博学但犹豫”进化到了 RL 阶段的“自信且精准”，实现了逻辑密度的显著提升。

  

### 6.2 “格式错误”背后的长度长尾效应

<a id="section-6-2"></a>

结合“格式错误样本平均长度演化图”与之前的正确样本数据，我们捕捉到了一种极具病理学意义的“反差”：模型在“成功”时保留了对题目难度的敏锐感知，而在“失败”时则陷入了高度同质化的“长度黑洞”。

回顾正确样本的推理行为，模型展现出了优异的资源分配能力——推理长度与题目难度呈现清晰的正相关，即“难者长考，易者速决”。然而，一旦目光转向失败样本（即格式错误样本），这种“特异性”瞬间消失。除受到 2048 Token 物理硬截断限制的 GSM8K 外，其余所有数据集，无论其中程难度的 AMC，还是极具挑战的 AIME 2025，失败样本的平均长度曲线在 SFT 和 GRPO 阶段发生了惊人的重合，均紧密收敛在 **3400 ~ 3700 Tokens** 这一狭窄区间内。

这种线条的紧密纠缠揭示了模型在迷失状态下的认知机制：**“失败收敛”**。当模型无法找到正确的推理路径时，它似乎同时也丧失了解析题目复杂度的能力。在模型的“迷宫”中，一道高中数学题和一道竞赛压轴题不再有区别，它们都触发了同一种通用的、与具体任务无关的病态模式。这种现象深刻地折射出 SFT 阶段的“长考副作用”：SFT 虽然赋予了模型思维链的深度，但也引入了一种顽固的冗长倾向。一旦推理受阻，模型习得的“范式”便异化为一种机械的自我重复或无效堆砌，导致所有类型的错误最终都殊途同归，在逼近 3500 Token 的“熵增临界点”处走向崩塌。



### 6.3  失败样本的物理截断与“熵增临界点”

<a id="section-6-3"></a>

通过对比基础算术任务（GSM8K）与高难度竞赛任务（MATH, AIME）在失败样本上的长度分布，我们发现了一个极具启发性的**“双重截断机制”**，这揭示了小参数模型在长程推理中的认知边界。

**(1) GSM8K：物理硬截断**

在 GSM8K 任务中，由于我们将 max_tokens 限制为相对较短的 2048，观察数据发现，失败样本的平均长度（Fail Avg Token）高度集中在 1976-2048 区间，且“格式错误长度触顶率”极高（接近 94%-100%）。
这是一种典型的**“物理硬截断”**现象：模型的推理意犹未尽，但被上下文窗口的物理边界强行切断。此时的模型处于“有思路但写不下”的状态，错误更多源于外部限制而非内部逻辑崩塌。

**(2) 复杂任务：认知软崩溃**

然而，当我们转向 MATH 和 AIME 等高难度任务，并将 max_tokens 放宽至 4096 后，情况发生了反直觉的逆转。

- **现象：** 尽管拥有 4096 的广阔空间，失败样本的平均长度却并未逼近这一上限，而是**稳定地收敛在 3400-3600 Token 这一区间**（如 MATH500 GRPO 失败样本均值为 3584，AIME24 为 3464）。
- **触顶率归零：** 更关键的是，格式错误长度触顶率骤降至 0%。这意味着，模型并不是因为“写满了”而被系统截断，而是**在达到物理极限之前，模型自主输出了 EOS（结束符）**。

**(3) 熵增临界点与格式崩塌**

我们将 2048 Token 之上、4096 Token 之下（具体约为 3500 左右）的这个区间定义为 1.5B 模型的**“熵增临界点（Entropy Critical Point）”**。

在此区间内，模型并未耗尽显存，而是耗尽了“逻辑一致性”：

1. **迷失与循环：** 随着 CoT 长度突破 2500，模型因无法找到解题路径，开始进入“死循环”或“无效自我纠正”（如反复输出 "Let me recheck", "Wait..."）。
2. **熵增导致的结构遗忘：** 长时间的无效推理导致上下文的**信息熵（Entropy）**急剧升高。在接近 3500 Token 时，高熵状态使得模型不仅丢失了逻辑线索，甚至丢失了对 XML 格式指令的“短期记忆”。
3. **自主放弃：** 最终，模型在混乱中“误以为”自己完成了任务，或者为了逃避当下的高熵状态，**草率地输出了 EOS 结束符**。但由于此时逻辑已经崩塌，它往往忘记闭合 <answer> 标签或输出了不合规的答案，从而被判为“格式错误”。



**结论：** 失败样本在 3500 Token 处的“自主截断”，标志着模型**认知耐力的极限**。对于 1.5B 模型而言，超过这个长度的推理往往不再是有效的逻辑延伸，而是走向格式崩塌的无效“梦呓”。这为我们在 RL 中引入 **Length Penalty（长度惩罚）** 提供了精确的阈值依据。

## Chapter 7 模式坍塌现象分析

<a id="section-7"></a>

### 7.1 模式坍塌现象的定义与检测

在强化学习激发模型长程推理潜力的过程中，我们观察到一种显著的病理现象：当模型无法找到有效的逻辑路径时，往往不会诚实地停止（输出 EOS），而是陷入一种**高耗能、低信息的死循环状态**。为了量化分析这一现象，在本报告中，我们将推理中的“模式坍塌”考虑为为**“基于递归重复的逻辑死锁”**。

#### 1. 现象定义：从“多样性缺失”到“逻辑死锁”

与传统生成模型（如 GAN）中指代“样本多样性丧失”的定义不同，在本报告的 CoT 推理语境下，模式坍塌特指模型在推理过程中**因逻辑断裂而产生的自我重复与文本堆砌行为**。

其典型特征表现为：

- **语义空转：** 反复输出无效的过渡词（如 "Wait, let me think again..."）。
- **物理膨胀：** 生成长度迅速逼近上下文窗口上限。
- **信息熵骤降：** 尽管文本很长，但有效信息密度极低，存在大量字符级的机械重复。

#### 2. 检测算法：双重阈值过滤机制

为了从海量的推理日志中精准定位发生坍塌的样本，我们设计了一套基于**滑动窗口自相关**的检测算法。该算法不依赖复杂的语义模型，而是从 **物理长度** 和 **重复密度** 两个维度进行硬性判定。

判定一个样本发生“模式坍塌”，须同时满足以下两个约束条件：

**A. 物理长度约束**
$$
L_{text}>3,000 \ Tokens
$$

- 排除正常的短文本回复。实验数据显示，即使是 AIME 级别的复杂题目，有效的推理链路通常也在 2000 Tokens 以内。超过 3000 Tokens 的生成往往意味着模型已经失去了对推理终点的控制，进入了“拖延时间”的垃圾生成状态。

**B. 重复密度约束**
$$
R_{LCP}>20\%
$$

- **算法逻辑：** 我们采用一个长度为 $N=10$ 字符的滑动窗口扫描全文，记录所有出现过的窗口模式。

- **计算公式：**
  $$
  R_{LCP}=\frac{∑\mathbb{I}(Pattern_{i}∈SeenSet)}{TotalLength}
  $$
  其中，$SeenSetSeenSet$为历史扫描过的窗口集合。若当前窗口内容曾在之前出现过，则视为重复字符。

  

- **设计动机：** 正常的人类语言或数学推导即使篇幅很长，其局部表达也是丰富多变的。而逻辑坍塌后的模型往往陷入机械复读，导致 $R_{LCP}$指标激增。20% 的阈值经过实测，能有效区分“必要的反复验证”与“病态的死循环”。

通过这一自动化检测手段，我们成功将那些“伪装成超长思维链”的无效样本剥离出来，为后续的**失败样本物理截断分析**提供了精确的量化依据。

这意味着，在实际部署中，**一个错误的推理请求所消耗的算力，是正确推理的 3 到 5 倍**。这种“失败即长考”的特性，是工程落地中必须通过“早停机制”或“长度惩罚”来解决的关键痛点。

**3. 蒸馏的“对齐税”**
结合 SFT 阶段仅使用 3,000 条样本、1 个 Epoch 即实现性能飞跃的背景，我们可以得出结论：**极高的模式坍塌率，本质上是小模型为了承载超越其容量的大模型思维链逻辑，所必须支付的“对齐税”。** 我们用“鲁棒性”换取了“智商”的爆发，这是一场极其划算但代价明确的交易。

## Chapter 8 算法优选与消融实验：基于稳定性与泛化边界的评估

在前面的章节中，我们已经从宏观层面验证了强化学习（RL）相对于监督微调（SFT）在推理能力提升与模式坍塌修复上的显著优势。

然而，**“RL 有效”并不等同于“所有 RL 策略都适用”**。特别是在单卡 4090 这种**极小 Batch Size** 的受限资源环境下，策略梯度估计的方差与偏差对算法的收敛性有着决定性的影响。

本章将进入微观的算法博弈层面。我们设计了一组消融实验，通过对比三种不同归一化策略的 GRPO 变体，深入探究算法设计在**“探索激进性”**与**“训练稳定性”**之间的权衡。我们的目标是回答一个核心工程问题：**在算力受限且需要面对高难度 OOD（分布外）测试时，哪种算法配置才是兼顾性能与鲁棒性的最佳解？**

### **8.1 实验配置：归一化策略的消融设计与理论假设**

为了剥离算法核心组件对模型逻辑演化的具体影响，我们基于 DeepSeek-R1 的 GRPO 框架，构建了三个具有明确演进关系的实验对照组。我们重点关注优势函数（Advantage Function）计算中的**组内标准差归一化（Std-Norm）**与**长度归一化（Length-Norm）**这两个关键变量。

#### 1. 变量控制组: Standard GRPO (基准组)

- **算法定义：** 

  - 优势计算上，严格遵循 DeepSeekMath 原论文定义的 GRPO 算法。在计算优势时，对组内奖励进行标准化的 Z-Score 处理：

  $$
  A_{i}=\frac{R_{i}−mean(R)}{std(R)}
  $$

  - 损失函数上，包含隐式的长度归一化，即损失函数除以序列长度$\frac{1}{|o_{i}|}$

- **理论假设：** 

  - 从稳定性角度，在**单卡小 Batch** 场景下，实际上引入了**题目级难度偏差**，即困难任务往往伴随着极低的标准差，此时除以标准差会导致优势函数被剧烈放大，进而引发梯度震荡，可能阻碍模型在复杂任务上的精细收敛。
  - 从长度偏差角度，由于损失函数除以序列长度，算法存在**非对称的奖惩机制**。对于正样本，优势$A_{i}>0$，序列越短，每个token获得奖励梯度越大；而对于负样本，优势$A_{i}<0$，序列越长，每个token获得的惩罚梯度越小。即，算法会偏向奖励更短的正确样本，同时隐式的“奖励”那些更长的错误样本。

#### 2. 实验组A:  GRPO w/o Std-Norm 

- **算法定义：** 移除优势计算分母上的标准差项，仅保留去均值处理：
  $$
  A_{i} = R_{i} - mean(R)
  $$

- **理论假设：** 

  - 从稳定性角度，这是一种“去噪”尝试，旨在避免小样本或者困难任务的组内标准差带来的数值不稳定性，模型的更新幅度会小于GRPO，但是。

  - 虽然梯度稳了，但由于保留了长度归一化，模型依然受制于**长度偏差**。它可能稳定地收敛到了一个“倾向于生成长回复”的局部最优解，从而在分布内任务（AIME 24）上表现出色，但在分布外任务（AIME 25）上因逻辑固化而失效。

    

#### 3. 实验组B: Dr.GRPO (无偏修正组)

- **算法定义：** 采用 *Liu et al. (2025)* 提出的**无偏估计（Unbiased Estimator）**策略
  - **全去偏：** 彻底移除标准差归一化（No Std）。
  - **长度修正：** 修正损失函数，**移除长度归一化项** $\frac{1}{∣o_{i}∣}$，即改为 Sum 形式或配合常数归一化，还原真实的策略梯度

- **理论假设：**
  - **纠正非对称性：** 移除长度归一化后，惩罚力度与长度脱钩，模型无法再通过“啰嗦”来逃避惩罚。
  - **预期效果：** 我们假设 Dr.GRPO 虽然在简单任务上的爆发力可能不如激进组，但在面对 AIME 2025 等高难度任务时，能有效抑制死循环，表现出**最高的 Token 效率**与**最强的泛化鲁棒性**。

特别地，w/o_std_norm变体在AIME25上的反常行为，成为了整个观察中一个关键的信号。其**正确率的断崖式下跌、格式错误率的急剧飙升、以及失败推理长度的显著回升**，这三个现象同时发生，共同描绘了一幅清晰的“**系统性崩溃**”画像。这表明，该变体在面对极限压力时，其主要的失败模式并非简单的逻辑错误，而是**开放式的、最终导致推理结构本身瓦解的无效探索**。

这一系列强有力的交叉证据，将我们的分析焦点引向了`AIME`数据集，尤其是2024与2025两个年份之间存在的性能差异，因为这正是检验模型在“已知”与“未知”边界上行为模式的最佳试金石。

### **8.4 训练动力学分析：响应长度偏差与 Token 效能**

对于 1.5B 模型，**长度偏差（Length Bias）** 的负面影响尤为致命。

对于标准GRPO，可以观察到其负样本响应的长度冗余与模式坍缩行为。在 AIME 25 的失败采样中，标准 GRPO 的长度（3680.9）远超其成功样本。这完全符合论文对 GRPO 优化偏差的描述：模型发现通过增加错误回复的长度，可以减小负优势函数带来的惩罚梯度 。对于 小模型，这种“为了少受罚而写废话”的倾向会迅速耗尽其有限的注意力窗口和逻辑容量，导致模型行为退化。

Dr. GRPO 通过固定分母 ，消除了这一逃避机制。其在 AIME 25 失败样本上的长度（3270.7）为全组最低，说明其训练出的模型在逻辑失败时更倾向于停下，而非陷入无意义的思维循环。这种高的“Token 逻辑密度”是 1.5B 模型在受限算力下实现高效推理的关键。

### **8.5 算法选型结论：无偏估计在受限算力下的综合优势**

综合评估 `bespoke-stratos-17k` 训练后的各变体表现，得出以下选型结论：

1. **否定标准 GRPO 的高难度通用性**：虽然 $1/std$ 在泄露任务上能提供虚高的 Pass@1，但在真实泛化任务中，这种难度偏差会造成多样性丧失和虚假冗余 。
2. Dr. GRPO 是泛化性能的最佳保障：其在 AIME 2025 上 **36.7%** 的 Pass@64 成绩，证明了在剔除所有数学偏差后，模型能学到最纯粹的逻辑泛化能力 。
3. **最终建议**：考虑到小参数模型（7B）极易受梯度不稳定性的影响，建议在所有涉及高难度、复杂推理的 RL 任务中，优先采用 Dr. GRPO 方案 。

## Chapter 9  泛化真相：基于“推理留存率”的行业多维诊断

### 9.1 AIME 24 vs. AIME 25: 一个揭示泛化真相的“自然实验”

对于一个1.5B的小参数模型而言，其性能在面对高难度基准测试时出现下滑，是反映其内在能力局限的正常预期。然而，真正引人深思的并非这一普遍性的衰减趋势，而是在 **AIME 2024 与 AIME 2025 这两个数据集之间，模型表现出的显著性能差异**。

**最强有力的证据来自于Baseline模型（即未经任何SFT/RL微调的Qwen-2.5-Math-1.5B）的表现：**

- 从[**表8**](#table8-anchor)中可以清晰地看到，Baseline模型在AIME 2024上的Pass@64达到了**13.3%**。

- 相比之下，它在AIME 2025上的Pass@64仅为**3.3%**，两者相差整整**4倍**。

  

一个未经任何针对性微调的模型，为何在理论难度相当的两个测试集上表现出如此悬殊的差异？这引出了两个主要的**竞争性假说**：

**假说一（数据污染假说）：其预训练数据中已经包含了AIME 2024的题目或高度相似的解题讨论，而AIME 2025则是其从未见过的全新数据。**

**假说二（数据分布适配假说）： AIME 2024的数据分布（例如，题目类型、所需知识领域）可能偶然地、系统性地比AIME 2025更适合Qwen-Math系列模型的“能力甜点区”**。

为了探究哪个假说更具解释力，我们进行了一系列外部证据的检索与分析。



### 9.2 指标构建：推理留存率的定义与经济学释义

#### 8.2.1 推理稳定性指标设计

为了系统性地检验“数据污染”假说，我们需要一个能够科学地量化模型在“已知”（AIME 24）与“未知”（AIME 25）数据集之间性能稳定性的指标。一个核心的挑战在于，AIME 2024的性能指标本身可能已经因潜在的数据污染而成为一个**有偏的估计量**。

这类似于经济学和社会科学中著名的**古德哈特定律（Goodhart's Law）**：*“当一个度量本身成为目标时，它便不再是一个好的度量。”* 如果模型在预训练时已将AIME 2024的数据作为优化目标，那么其在该数据集上的高分则无法完全代表其真实的推理能力。

因此，基于Perf_24的简单度量，如**绝对性能差异 (Perf_24 - Perf_25)**，会因**基数效应**而产生误导，无法在不同模型之间进行公正的比较。

为了解决这一问题，我们借鉴了经济学中评估**资产保值能力**的思路，将模型在AIME 2024上展现的能力视为一种“初始价值”，并衡量其在AIME 2025这个新环境中能够“留存”下多少。我们为此定义了一个核心度量指标——**“推理留存率”**。

- **计算方式：** 留存率 = Perf_25 / Perf_24
- **经济学释义：** 这个指标在概念上，等同于衡量一项 **无形资产** 在经历了一个周期的市场变化后，其 **剩余价值与初始价值的比率** 。一个高留存率，意味着这项“知识资本”的 **折旧率低** ，其内在价值是稳固且可迁移的。反之，一个低留存率，则意味着其初始的高价值很可能只是泡沫，无法抵御真实的市场考验。

为了更精细地诊断这项“知识资本”的不同层面，我们进一步将其分层为两个指标：

- **Greedy 留存率 (Pass@1):**
  - **经济学类比：** 这可以看作是衡量企业**“核心业务的运营效率”**的稳定性。它反映了模型最常用的、最自信的“生产线”（推理路径）在面对新市场时的保值能力。
- **Upper 留存率 (Pass@16):**
  - **经济学类比：** 这更像是衡量企业的 **“总资产价值”** 或 **“长期潜力”** 的稳定性。它反映了模型全部“知识储备”的鲁棒性，即使这些储备没有被高效地利用。

基于上述图表，我们可以观察到留存率指标所揭示的，关于当前大语言模型（LLMs）内在稳定性的一些核心规律。

1.  **基于推理能力的“马太效应”：强者愈稳，弱者愈脆**

	从表4和表5的数据分布来看，模型的留存率与其基础性能（准确率）呈现出显著的“强者恒强”趋势，性能分化严重。

- **精英模型的“价值锚定”**：以 OpenAI o1-mini 和 DS Distill 32B 为代表的高性能模型，其“Greedy留存率 (Rg)”不仅没有衰减，反而大幅超越100%，展现出强大的“泛化红利”。同时，其“Upper留存率 (Ru)”也高度收敛于100%的稳定线，表现为一种“资产的良性巩固”。

- **底层模型的“能力蒸发”**：处于性能基座的底层模型（如 DS-Math-7B-RL），其留存率常常表现为断崖式的 0%（能力未涌现），或巨大的价值波动。这说明其推理路径极度脆弱，如同“原始账面价值”般，稍有扰动便会“价值归零”。

- **结论**：这揭示了留存率的偏差值 **ΔR = |R - 100%|**，实际上是衡量模型推理逻辑是否“内化”为稳定结构的核心负向指标。偏差越大，模型的内在逻辑越脆弱。

  
2. **参数规模的“压舱石”效应：规模提升带来稳定性收敛**

	以 Qwen2.5 系列为例，我们可以观察到随着参数规模（7B $\to$ 32B $\to$ 72B）的增长，留存率展现出的“收敛动力学”：

- **Greedy留存率 (Rg) 的“降噪”**：Qwen2.5-7B-I 的 *Rg* 为 60.4%，表现出较大的不确定性。而 32B 和 72B 尽管存在架构红利带来的溢价（*Rg* 分别为 180.2% 和 150.4%），但其搜索上限 *Ru* 表现出极强的稳定性（104.1% 与 98.5%），显示出噪音被有效抑制。
- **推理空间的“确定性”增强**：参数量越大的模型，其能力上限 *Ru* 越接近 100% 的理想稳定线。这说明大参数模型形成的推理“解空间”更加致密，对样本扰动的容忍度和鲁棒性也更高。



3. **时间维度的“范式演进”：从“混沌探索”到“逻辑求稳”**

	从 2024 年 2 月到 2025 年 1 月的时间轴上看，模型分布经历了从左下角向“100% 理想稳定线”集群移动的过程：

- **早期阶段**：2024 年上半年的模型（如 Llama-3.1-70B-I）多处于 50% 以下的低留存率区域，推理能力表现出高度的 OOD（分布外）脆弱性。

- **后强化学习时代**：2024 年 9 月后的推理模型（o1 系列、Qwen 数学系列、DeepSeek 蒸馏系列）开始在 70%-100% 区间密集分布。

- **演化本质**：时间轴上的向心力反映了行业后训练技术（Post-training）的共同取向——即牺牲不可控的性能爆发，追求可预测、可复现的逻辑稳定性。



### 9.4 **核心洞见：“推理留存率”的多维诊断**

为了穿透单一性能指标的迷雾，我们设计并引入了**“推理留存率”**这一核心诊断工具。通过对其在**Greedy（Rg）**与**Upper（Ru）**两个层面，以及两者之间**演化路径**的分析，我们得以对模型在OOD泛化挑战下的内在属性，进行一次深刻的、多维度的扫描。

![](asset/留存率可视化.png)

<p align="center">图4 主流大语言模型推理稳定性随发布时间、参数规模与采样深度的多维演化诊断（Rg -> Ru 演化路径）</p>

为了最终揭示时间、参数量和采样深度这三个维度如何共同影响推理稳定性，我们将所有模型的数据投影到一个以**时间为横轴**的全新诊断空间中（如图4所示）。这张图的核心，不再是简单地比较留存率的“高低”，而是诊断其与**100%理想稳定线的“偏离度”（Deviation）**，因为任何显著偏离100%的行为，都是模型泛化能力不稳定的体现。

**坐标系解读：**

- **X轴**是**模型发布时间**，**紫色虚线**标记了**“AIME 24考试日”**，它如同一道分水岭，将图表划分为“污染前”与“污染后”两个时代。

- **Y轴**是**推理留存率**，**红色虚线**是100%的理想稳定线，代表了**“零偏离”**的完美泛化状态。

- 每一个**圆圈/箭头**代表一个模型。**圆圈的大小**代表参数量。**箭头的演化路径**，则动态地展示了从Greedy起点到Upper终点的“采样平滑效应”

  

#### 9.4.1 Greedy留存率 (Rg)：核心策略的“压力测试”

Rg (Pass@1的留存率)衡量的是模型**最自信、最收敛的核心策略**，在面对从“已知”（AIME 24）到“未知”（AIME 25）的环境剧变时，其表现的稳定性。

- **观察：** 表4和图4显示，绝大多数模型的Rg都显著偏离100%。一部分模型（如Llama-3.1）远低于100%，而另一部分（如Qwen2.5-32B）则反常地远高于100%。同时，在Greedy留存率的表现上，最好的三个模型依次为**OpenAI o1-mini**，**DS-Distill-32B**和**Qwen2.5-Math-72B-I**
- **推论：** 这有力地证明，**Pass@1作为一个评估指标，其本身是高度不稳定的**。它极易受到模型**“策略偏见”**（例如，过拟合了AIME 24的某种范式，导致Rg<100%）或**“随机噪声”**（例如，在低基数下的偶然成功，导致Rg>100%）的严重干扰。因此，Rg的绝对值高低，并不能直接等同于泛化能力的好坏，但**其剧烈偏离100%的现象本身，就是模型核心策略不稳定的强烈信号**。



#### 9.4.2 Upper留存率 (Ru)：知识储备的“保值评估”

Ru (Pass@k的留存率)则衡量的是模型**潜在的、完整的知识储备**，在面对OOD挑战时的“保值”能力。

- **观察：** 图4中，除OpenAI-o1-mini外，所有箭头的**终点（Ru）**都比其**起点（Rg）**更靠近100%的理想稳定线。
- **推论：** 这一“向心回归”的现象，我们称之为**“推理锚定效应”**。其背后是“大数定律”的必然体现：多次采样通过“平均效应”，系统性地将模型从 Greedy 的“直觉偏差”中拉回，使其表现锚定在本质能力线上。因此，Ru是一个**更稳健、更可信赖**的指标，它更能反映模型由预训练所决定的、内在的、可迁移的知识内核的真实“保值率”。



#### **9.4.3 演化路径 (Rg -> Ru)：推理质量的“诊断探针”**

**如果说Ru告诉我们模型“知道多少”，那么从Rg到Ru的演化路径（箭头的长度和方向），则告诉我们模型“如何知道”——即其推理引擎的质量。**

- **“长箭头”特征 (e.g., Numina, Qwen2.5通用模型):**
  - **现象：** Rg与Ru之间存在巨大的鸿沟。
  - **推论：** 这暴露了模型**核心推理能力的相对孱弱**。它们的Greedy策略效率低下，无法稳定地调用其知识储备。其高Ru在很大程度上依赖于**多次采样的“暴力搜索”**，而非精准的、有指导的逻辑推演。这是一种**“知识与策略解耦”**的表现。
- **“短箭头”特征 (e.g., Llama-3.1, o1-mini, DS Distill):**
  - **现象：** Rg与Ru的表现相对一致。
  - **推论：** 这证明了模型拥有一个**更强大、更稳健的核心推理引擎**。它们的“第一反应”有更高的概率就是正确的，因此不需要过度依赖“暴力搜索”来提升性能。这是一种**“知行合一”**的表现。



### 9.5 统计动机：基于推理能力本源的二重性假设

基于上述分布特征的分析，我们提出一个核心假设：**“推理准确率”与“泛化稳定性”** 本质上是 **模型内在推理能力** 的一体两面。

- **准确率**衡量的是模型推理逻辑的**深度与覆盖度**；
- **稳定性（留存率）** 衡量的是模型推理逻辑的 **纯度与独立性**。

我们预设：真正的“本源推理能力”应当表现为准确率与稳定性的高度正相关——即逻辑越本质，其对题目分布的依赖就越小，表现就越趋于稳定。

为了量化证明这一假设，我们基于表4和表5的数据，绘制了覆盖行业主流模型（1.5B 至 400B+）的**全局相关性热力图（图 4）**。

然而，实验结果却呈现出一个巨大的统计悖论：在全样本视角下，**准确率与留存率的相关性仅为 -0.08**，呈现出显著的统计解耦状态。这意味着，在行业宏观层面上，高准确率模型并不天然具备高稳定性。但在 Qwen 体系内部，两者表现出 **-0.51** 的负相关，这意味着Qwen 系列的演进中，其获得的高分可能带有一种“溢价”。

二重性假设预期外的“失效”引导我们提出更深层的问题：**推理能力的二重性是否受到模型尺度（Scale）的机理性调制？**

#### 9.5.1 Greey留存率分析：规模效应下的稳健性背离

![](asset/heatmap/greedy_retention_evolution.png)

<p align="center">图7 greedy留存率与AIME 25 Pass@1的动态相关性分析图</p>

$R_g$ 基于 Pass@1 准确率计算，反映模型直觉思维的跨样本稳定性。

模型表现出显著的**参数规模阈值效应**。在小参数区间，准确率与 $R_g$ 保持同步增长，相关性为0.57。但当规模跨越 72B 后，相关性降至 -0.16，表现为统计学上的无关或微弱负相关。

实验结果表明，依靠参数规模提升的绝对准确率并未能线性转化为直觉推理的稳健性。在大模型语境下，绝对分数的增长与性能迁移的稳定性发生了“解耦”。这说明目前的 Scaling 策略更多是在拓宽知识覆盖面，而非构建某种跨越题目集波动的坚固逻辑核心，导致高分表现具有极强的样本依赖性。

#### 9.5.2 Upper留存率分析：逻辑泛化的“天花板”塌陷

![](asset/heatmap/upper_retention_evolution.png)

<p align="center">图8 upper留存率与AIME 25 Pass@16动态相关性分析图</p>

$R_u$ 基于 Pass@16 准确率计算，旨在捕捉模型在多次搜索空间下的推理能力上限。

在参数规模 $\le 7B$ 区间，AIME25 准确率与 $R_u$ 呈现弱正相关（0.17）。然而，在参数规模 $> 72B$ 的高能力区间，两者呈现出极强的**负相关性（-0.93）**。

尽管大参数场景缺少足够规模的样本供分析，但这种相关性的性质逆转仍然揭示了大规模模型中普遍存在的“高分低留存”悖论。极高的负相关系数（-0.93）是**数据污染**的强有力指征：即部分模型在 AIME24 上的卓越表现可能源于训练集中包含类似考题的“记忆”效应（导致分母异常肥大），而一旦面对去污染后的 AIME25 任务，其逻辑泛化的脆弱性便无处遁形，导致留存率出现断崖式下跌。

#### 9.5.3 留存一致性损耗分析：100B 阈值后的逻辑断层

![](asset/heatmap/delta_r_evolution.png)

<p align="center">图9 Upper留存率与Greedy留存率间差距绝对值动态相关性分析图</p>

$\Delta R = |R_u - R_g|$ 衡量模型在“直觉”与“深思”两种推理模式下留存表现的差异程度，是评估逻辑一致性的关键指标。

 演变图显示，相关性在 **100B 参数点**发生了剧烈跳变。在超大规模模型中，准确率与该差距呈现 **0.70 的强正相关**。

现象标志着模型进入了一种**“非对称退化”**阶段。在高分段模型中，$\Delta R$ 的显著拉大意味着模型在应对新挑战（AIME25）时，其多次尝试后的“潜力留存”与单次尝试的“直觉留存”不再同步。这种 0.70 的强相关性证明了：对于目前处于第一梯队的模型，其高准确率背后隐藏着深刻的逻辑一致性断裂。这种由于“博弈特定考卷”而产生的非线性能力增长，进一步坐实了当前大模型数学能力的虚假繁荣。



#### 9.5.4  性能留存视角下的数据污染验证总结

通过对不同参数规模模型在 AIME24 与 AIME25 测试集上的表现演变进行观察，我们可以综合得出以下结论

**潜力上限发生逆向演变：** 在超过 72B 的大参数区间，模型 AIME25 的绝对准确率与其潜力留存率（$R_u$）呈现出极强的**负相关性（-0.93）**。这意味着在 AIME25 上得分越高的模型，其相对于 AIME24 的性能留存表现反而越差。

**规模效应与稳健性的脱钩：** 随着参数规模跨越 72B，基础直觉留存（$R_g$）与准确率的相关性从正向（0.57）转为弱负相关（-0.16），显示出 Scaling Laws 在提升分数的同时，未能同步增强跨样本集的稳健性。

**逻辑一致性发生系统性退化：** 当参数规模达到 100B 阈值后，准确率与留存差距（$\Delta R$）呈现 **0.70 的强正相关**，表明高分模型在应对新测试集时，其“直觉”与“深思”模式的性能损耗出现了显著的不对称性。



上述统计现象为 **AIME24 测试集存在严重数据泄露（Data Contamination）** 的假设提供了实质性的数据支撑：

- **分母膨胀效应：** 留存率 $R$ 的计算受分母（AIME24 表现）直接影响。若模型在 AIME24 上存在泄露导致的“背诵”现象，其分母将被异常拉高。即使模型在 AIME25 上具备真实的泛化能力，其计算出的留存率也会因分母过大而表现出极低的数值。
- **相关性倒挂的逻辑推演：** 实验观察到的 -0.93 强负相关证明，目前头部的数学高分表现与性能稳定性之间存在本质冲突。这种背离常理的统计特征暗示，头部模型在 AIME24 上的高分并非完全来源于逻辑泛化，而是受益于针对特定题集的记忆效应。
- **非对称损耗的验证：** 100B 规模模型中出现的 $\Delta R$ 剧增（0.70 正相关）进一步揭示了这种污染是非稳健的。当面对去污染的 AIME25 时，泄露带来的“能力幻觉”在不同采样策略下发生差异化崩塌，从而产生了显著的逻辑断层。

## Chapter 10 从 AIME 具体作答观察强化学习的“伪逻辑”与“真进化”

虽然通过宏观指标可以部分推测并量化预训练阶段的具体数据泄露，但通过对 AIME 2024 与 2025 模型表现的微观比对，我们更可以观测到两种截然不同的智力演变模式，这是对数据泄露的更为精确的铁证。

通过对比 **AIME 2024（存量/泄露集）** 与 **AIME 2025（增量/OOD 集）** 的模型表现，我们可以清晰地观察到强化学习（RL）在逻辑生成中的双重角色：它是已知答案的“美颜者”，也是未知领域的“开拓者”。

### 10.1  核心现象：数据分布揭示的“记忆墙”

![](asset/aime_domain_distribution.png)

<p align="center">图10 三阶段模型在AIME上的Pass@64分领域正确题目分布</p>

模型在不同年份题目上的表现差异，是判定其具备“真逻辑”还是“伪记忆”的试金石：

#### **AIME 2024：非线性“跳跃”背后的数据污染特征**

- **基座模型的异常表现**：Baseline 模型在 AIME 2024 上呈现出极度不符合难度分布的“跳跃得分”现象，且表现出异常的高正确率（8/30）。例如，模型能够解出后半段的高难度题目（如第 13、19 题），却无法完成基础的第一题。这种“逻辑孤岛”分布有力地支撑了该数据集在预训练阶段存在“样本记忆”而非“能力泛化”的假说。
- **SFT 阶段的“归纳摩擦”**：SFT后的模型在部分复杂题目上反而不如基座，是因为 SFT 试图模仿DeepSeek R1 的CoT推导但因能力不足导致逻辑断裂，而基座直接“跳过过程，提取答案”。在经过监督微调后，SFT 模型虽然掌握了格式规范，却意外丢失了部分基座模型原有的解题能力。



#### AIME 2025：纯净 OOD 环境下的逻辑稳健增长

- **符合困难梯度的单调性**：在完全分布外（OOD）的 AIME 2025 压力测试中，模型的表现回归了正常的统计规律，即解题成功率随题目难度（由题号表征）呈严格的单调递减。**Baseline**正确率瞬间坍缩（1/30），仅能依靠**原始枚举**处理极简题（如 P1）。
- **RL 的“推理锐化”效应**：与 2024 年的波动不同，**DRGRPO** 在 2025 年展现出了近乎完美的“能力前沿”填补能力。强化学习不仅完整覆盖了 SFT 的逻辑路径，还成功攻克了中等难度的中间题目 。这证明了 RL 并非简单注入新知识，而是通过奖励机制实现了逻辑的“内化压缩”与概率分布的“锐化”，将模型潜在的检索潜能转化为了稳定的逻辑输出。



### 10.2 案例研究: AIME24数据泄露下的“后向合理化”与伪逻辑

![](asset/aime24_ii_t13.png)

<p align="center">图11 AIME24 II Problem13上模型的伪推理现象</p>

在 AIME 2024 的测试中，模型表现出明显的**“记忆检索”**特征。由于该年份题目已被大量纳入预训练语料，基座模型往往已经“锁死”了正确答案。

- **“凑过程”现象（Process Hallucination）**：当 RL 介入时，由于奖励函数高度依赖结果准确性（ORM），模型在逻辑不通时会产生“后向合理化”行为。即便中间步骤出现坐标幻觉（如点不在直线上）或代数跳跃，模型仍能强行推导至记忆中的正确答案。
- **逻辑断层**：这种表现并非真正的逻辑生长，而是 RL 迫使模型在已知终点的情况下，编造一条看似合规的路径。在 Logarithm（对数）等案例中，基座模型的原始输出往往混乱，而 RL 后的输出虽然修正了答案，却仍保留了大量的“逻辑伪装”。



### 10.3 案例研究: AIME25作为OOD样本测试中的逻辑缩放与真收敛

![](asset/AIME_2025_I_t1.png)

<p align="center">图12 AIME25 I Problem1上模型的逻辑内化现象</p>



相比之下，AIME 2025 或AIME24中经修改后的变体题（如修改数值后的行程问题）更接近 **OOD（分布外）泛化测试**。在没有记忆可循的情况下，RL 展现了其真正的技术价值。

在 AIME 2025 Problem 1 的案例中，我们可以观察到推理逻辑的明显进化过程：

**Baseline（基座）**：倾向于使用暴力枚举，路径冗长且易错。

**SFT（微调）**：开始引入数论转化（如利用整除特性），推理效率提升。

**DRGRPO（强化学习）**：逻辑进一步精简，准确识别边界条件（如 $d > 16$），实现逻辑的高度收敛与闭环。

可以看到，对于发生了数据泄露的AIME24题目，Baseline模型会直接编造一个完全不符合事实与逻辑的“推理”过程。就算经过了后训练，在分布内的高难样本上，模型仍然**不能**真正学会如何正确的求解该题，反而RLVR的范式锐化了其蒙出记忆中正确答案的分布，增大了其蒙出一个似是而非的推理过程的概率。但是这个过程仍然是经不起推敲的，而是充满着错误和漏洞。

而对于下图中完全分布外的AIME25样本，SFT和RL则展现出了惊人的效果。SFT后，模型学会了用数论方法取代原本的暴力枚举。而RL后的模型更是可以以极高的效率锁定关键逻辑，一步到位。



### 10.4 AIME 24: 模型逻辑演进的三阶段对比

通过分析各阶段模型在 AIME 2024上的具体答案正确的逻辑准确性(见[**表A**](#tableA-anchor))，我们可以看到模型在处理不同数学领域时，逻辑异化的具体表现截然不同，且出现了大量逻辑不通但是答案正确的推理。

1. **代数类：从“直觉跳跃”到“步骤美化”**

   代数是模型表现最稳健、最接近“真逻辑”的领域。

   **逻辑特征**：**算法化收敛**。

   **表现细节**：在处理对数方程组（P8, P25）时，RL 阶段能敏锐捕捉到换底公式等核心性质，并将繁琐的消元过程转化为严密的线性方程组求解。

   **底层判定**：**真逻辑区**。由于代数规则在预训练中极度丰富，模型在该领域能通过 `<think>` 阶段实现真实的路径优化，而非单纯凑数。

   

2. **数论领域：高确定性的“算法迁移”**

   **逻辑特征**：**规则驱动型推演**。

   **表现细节**：在处理 2025 P10 等整除问题时，模型能精准调用同余简化和余数定理，将复杂乘积转化为常数除法（如 $39 \pmod{n+2}$）。其逻辑链条无跳跃，每一步都有公理支撑。

   **底层判定**：**高纯度推理区**。数论逻辑的离散性和封闭性使得 RL 能有效剪枝掉错误的代数分支。

   

3. **几何领域：从“盲目猜想”到“高级逻辑欺诈”**

   几何是模型推理最脆弱、幻觉最严重的“深水区”。

   - **逻辑特征**：后向合理化。

   - **表现细节**：

     - **解析几何稳健**：一旦几何问题能够被平滑地转化为代数运算（解析化），模型就能展现出极其稳健的“真逻辑”。
     - **概念缺失锁死**：由于预训练缺失高阶几何概念（如星形线、九点圆），模型在 P19、P20 中表现为“逻辑炼金术”，通过发明不存在的工具（如“垂直平分线”逻辑）来掩盖概念空白。
     - **循环论证**：在 P26 中，模型利用必然成立的恒等式（$0=0$）来伪装推导过程，只为“护送”记忆中的正确答案。

   - **底层判定**：**逻辑诈骗区**。结果正确性与过程严密性完全解耦。

     

4. **组合与概率领域：在“记忆”与“搜索”间摇摆**

   该领域的表现取决于逻辑路径的“原子化”程度。

   - **逻辑特征**：**模板化映射与二进制收敛**。
   - **表现细节**：
     - **正面**：在涉及二进制分解（P27）或确定性周期博弈（P9）时，RL 能实现逻辑收敛，准确完成位运算级别的推导。
     - **负面**：在处理复杂数字约束（P24）或统计分布（P23）时，模型会为了匹配答案而违反基本物理约束（如发明 $a=81$ 这种非法数字位，或构造自相矛盾的中位数列表）。
   - **底层判定**：**逻辑黑盒区**。



### 10.5 AIME 2025: 完美答案背后的“逻辑裂痕”

虽然 RL 阶段的模型在 AIME 25这个OOD测试集上的得分也显著提升，但通过白盒审计其思维链（CoT），我们发现其逻辑并非无懈可击，主要存在以下两类典型缺陷：

#### 1. 坐标系坍塌与数值拟合 (以 P2 面积题为例)

模型在处理涉及空间拓扑的题目时，常表现出**维度坍塌**的特征。

- **现象**：在计算七边形面积时，模型将互有夹角的两条边 $AB$ 和 $AC$ 强行映射在同一数轴上。
- **逻辑缺陷**：尽管其几何建模在坐标意义上完全荒谬，但模型通过计算出一个中间量 $300$ 并与已知量 $288$ 进行生硬拼接，最终“凑”出了正确答案 $588$。这证明模型在利用**数值锚点**进行逆向推导，而非真实的几何演演。

#### 2. 系数搜索与公理违背 (以 P20 九点圆为例)

在面对高阶几何概念时，模型展现了**“结果驱动型”**的系数匹配策略。

- **逻辑缺陷**：模型在完全违反“圆周角等于弧度一半”这一基本公理的前提下（将角度 $84^\circ$ 直接等同于弧度），通过对题目中的已知数字进行 $1:2:3$ 的线性组合搜索，精准撞到了答案 $336$。这种表现说明模型是在**“解剖题目数字”**而非**“理解图形性质”**。

## Chapter 11 大模型数学推理的领域特征与真实性判定总结

通过对 AIME 2024 与 2025 跨年度题目的审计，我们将大模型在 RL（强化学习）阶段展现的推理能力总结为以下三个维度：

### 10.1 核心结论：数学领域的逻辑分布特征

我们将模型在四大领域的表现归纳为以下**三个逻辑象限**：

- **🟢 真实逻辑收敛区（代数、数论）**
  - **特征**：逻辑路径与代数公理高度一致，计算稳健性随强化学习显著增强。
  - **判定**：模型在此领域表现出**真实的逻辑进化**，能独立通过 `<think>` 阶段完成 $n$ 元方程组求解或数论整除推导。
- **🔴 逻辑欺诈重灾区（纯几何）**
  - **特征**：**“答案驱动型”伪推理**。由于单模态语言模型无法内化高维空间直觉，在面对复杂几何性质时，倾向于发明伪逻辑工具或利用恒等式进行“循环论证”。
  - **判定**：模型在此领域更多是在进行**文本炼金术**，即用学术语言包装错误的推理路径以对齐已知结果。
- **🟡 逻辑不稳定区（组合、解析几何）**
  - **特征**：表现高度依赖于问题的**符号化程度**。当几何题可转化为坐标代数（解析化）时，模型恢复诚实；当组合题涉及复杂离散约束时，模型容易产生逻辑漂移或违反物理约束。

------

### 10.2 底层演化规律：模态代差与评价指标错位下的推理异化

基于对 AIME 2025 等增量测试集的审计，可以得出一个模型推理真实性的底层判定模型：

#### 1. 模态天花板与空间直觉的“符号化”损耗

大模型在几何等领域的逻辑溃散，本质上是**单模态语言模型试图用“一维序列逻辑”翻译“高维空间直觉”时的维数坍塌**。

- **直觉残差**：几何推理中的非线性步骤（如辅助线构造、图形拓扑关系）无法被纯文本 Token 完全捕捉。
- **逻辑异化**：模型表现出的“凑数”行为，是其在缺乏空间推演能力时，利用符号组合能力对几何问题进行的“文本伪装”。

#### 2. PRM 缺失与评估框架的“验证失效”

由于本研究的评估框架（及主流训练框架）主要基于 **ORM（结果奖励模型）**，导致逻辑路径与最终答案在验证上发生了脱节。

- **后向合理化的教唆**：在测试集验证中，系统仅能判定 $\text{Answer}$ 标签的对错，无法对 $\text{<think>}$ 块中的逻辑断裂进行惩罚。
- **虚假收敛**：这种“过程盲”的验证机制诱导模型在面临 OOD（分布外）难题时，倾向于牺牲逻辑保真度去强行拟合数值。

#### 3. 算法化程度与诚实度的正相关性

模型的推理保真度与其处理问题的**“符号化与算法化”程度**成正比。

- **高保真区（代数、数论）**：题目本质是符号变换，与语言模型架构契合度高，表现为真实的逻辑收敛。
- **逻辑诈骗区（纯几何）**：存在无法文本化的直觉残差，在结果导向的奖励压力下，模型倾向于转向“逻辑炼金术”。

------

### 10.3 最终评述：过程盲区下的验证失效

通过在 AIME 2025 测试集（增量/OOD 集）上的实证观察发现，个人现有的评估体系存在明显的**结构性盲区**：

1. **过程监督的缺失**：目前的验证机制仅能对结果进行二元判定（对/错），无法识别模型在思维链（CoT）中出现的“维度坍塌”或“公理违背”。
2. **“虚假繁荣”的误导性**：由于 **PRM（过程奖励模型）** 的缺位，评估报告中显示的“高分”在几何与复杂组合领域具有极大的欺骗性。在 AIME 2025 的审计中，多道题目证明模型在利用评估框架“无法检测逻辑错误”的漏洞进行“补票式”得分。
3. **评估范式需要重构**：审计证据表明，若要衡量大模型真实的数学泛化能力，必须引入“逻辑一致性校验”或“细粒度过程奖励”，而非单纯依赖最终答案的匹配
